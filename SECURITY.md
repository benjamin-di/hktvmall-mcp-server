# Security

The server holds HKTVmall session cookies, which act like a password for the account they belong to. Please report
anything that could expose them, let one account act on another's basket, reach a host other than HKTVmall's, or
move money, privately through GitHub's
[private vulnerability reporting](https://github.com/benjamin-di/hktvmall-mcp-server/security/advisories/new) rather than
in a public issue.

Only the latest release is supported. Problems in HKTVmall's own site should be reported to HKTVmall.

The [permissions model](docs/PERMISSIONS.md) describes the independent browser, gateway, backend and provider boundaries, including disconnect and recovery.
